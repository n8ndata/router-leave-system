# คู่มือการติดตั้งระบบสำรองข้อมูล Google Sheets สำหรับ ROUTER Leave System

ระบบนี้รองรับการสำรองข้อมูลไปยัง Google Sheets ทั้ง 3 รูปแบบ:
1. **สำรองข้อมูล Real-time อัตโนมัติ:** เมื่อพนักงานส่งคำขอลา หรือหัวหน้างานอนุมัติ/ไม่อนุมัติ ข้อมูลจะถูกบันทึก/อัปเดตลง Google Sheet ทันที
2. **ปุ่มกด "ซิงค์ Google Sheet" บนหน้าระบบ:** สำหรับผู้ดูแลระบบ/หัวหน้างาน กดเพียงคลิกเดียวเพื่อส่งข้อมูลทั้งหมดขึ้น Sheet
3. **ดึงข้อมูลจาก Firebase อัตโนมัติ (Trigger):** สามารถตั้งเวลาใน Google Sheets ให้ดึงข้อมูลจาก Firebase ทุก 1 ชั่วโมง หรือทุกวันได้อัตโนมัติ

---

## ขั้นตอนที่ 1: สร้าง Google Sheets และติดตั้งโค้ด

1. เข้าไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `ROUTER - ข้อมูลการลาพนักงาน`
3. ไปที่เมนูด้านบน เลือก **ส่วนขยาย (Extensions)** > **Apps Script**
4. ลบโค้ดเดิมทั้งหมดในไฟล์ `Code.gs` ออก
5. คัดลอกโค้ดจากไฟล์ [`google-apps-script/Code.gs`](./Code.gs) ไปวางทั้งหมด
6. กดปุ่ม **บันทึก (Save)** (ไอคอนรูปแผ่นดิสก์ 💾 หรือกด `Ctrl + S`)

---

## ขั้นตอนที่ 2: เผยแพร่เป็น Web App (Deploy)

เพื่อให้ระบบหน้าเว็บสามารถส่งข้อมูล Real-time และกดปุ่มซิงค์มายัง Sheet ได้:

1. ที่มุมขวาบนของหน้า Apps Script กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกไอคอนรูปฟันเฟือง ⚙️ ข้าง "เลือกประเภท" เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Router Leave System Sync`
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (อีเมลของคุณ)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก ต้องเลือก Anyone เพื่อให้เว็บยิงข้อมูลเข้ามาได้โดยไม่ต้องล็อกอินบัญชี Google)*
4. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)**
5. หากมีหน้าต่างขึ้นมาขอสิทธิ์ ให้กด **ตรวจสอบสิทธิ์ (Authorize access)** > เลือกบัญชี Google ของคุณ > กด **ขั้นสูง (Advanced)** > กด **ไปที่ (ชื่อโปรเจกต์) (ไม่ปลอดภัย)** > กด **อนุญาต (Allow)**
6. เมื่อเสร็จแล้ว ระบบจะแสดง **URL ของเว็บแอป (Web app URL)** (รูปแบบ: `https://script.google.com/macros/s/.../exec`)
7. **คัดลอก (Copy) URL ของเว็บแอปนี้ไว้**

---

## ขั้นตอนที่ 3: นำ URL ไปใส่ในระบบหน้าเว็บ

คุณสามารถใส่ URL ได้ 2 วิธี (เลือกวิธีใดวิธีหนึ่ง):

### วิธี ก: ตั้งค่าผ่านหน้าเว็บโดยตรง (แนะนำ ง่ายที่สุด)
1. เปิดหน้าระบบลางาน
2. เข้าสู่ระบบในโหมด **หัวหน้างาน (Admin)**
3. ในส่วนจัดการหลังบ้าน กดปุ่ม **"ตั้งค่า Google Sheet"** (หรือกดปุ่ม **"ซิงค์ Google Sheet"** บนแถบหัวข้อ)
4. วาง URL ของเว็บแอปที่คัดลอกมาลงในช่อง แล้วกดยืนยัน (ระบบจะบันทึกไว้ในเบราว์เซอร์ให้ทันที)

### วิธี ข: กำหนดไว้ในไฟล์โค้ดของระบบ
เปิดไฟล์ `js/app.js` และ `index.html` แล้วค้นหาบรรทัด:
```javascript
const DEFAULT_GSHEET_WEBAPP_URL = '';
```
แล้วนำ URL มาวาง เช่น:
```javascript
const DEFAULT_GSHEET_WEBAPP_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
```

## ขั้นตอนที่ 4: ใช้งานการดึงข้อมูลอัตโนมัติจากฝั่ง Google Sheets (ตัวเลือกที่ 3)

เมื่อเปิด Google Sheets ขึ้นมาใหม่ จะมีเมนูพิเศษปรากฏขึ้นที่แถบเมนูด้านบนชื่อ:
**`🏢 ระบบลางาน ROUTER`**

เมื่อคลิกเมนูนี้ จะมีคำสั่งให้เลือกใช้:
- **🔄 ซิงค์ข้อมูลทั้งหมดจาก Firebase ทันที:** สั่งดึงข้อมูลล่าสุดจาก Firebase ลงตารางทันที
- **⏰ ตั้งเวลาซิงค์อัตโนมัติ (ทุก 1 ชั่วโมง):** บันทึกการตั้งเวลาให้ Google ดึงข้อมูลจาก Firebase มาอัปเดตลงตารางทุก 1 ชั่วโมง
- **⏰ ตั้งเวลาซิงค์อัตโนมัติ (ทุกวัน):** บันทึกการตั้งเวลาให้ Google ดึงข้อมูลมาอัปเดตลงตารางทุกวันช่วงเวลาเที่ยงคืน
- **❌ ยกเลิกการตั้งเวลาอัตโนมัติทั้งหมด:** ยกเลิกการตั้งเวลาทั้งหมด

## (ตัวเลือกเสริม) เปิดใช้ Token ป้องกัน Web App จากคนอื่นยิงข้อมูลเข้ามา

เว็บแอปเดิมเปิดให้ "ทุกคน (Anyone)" เรียกใช้ ใครก็ได้ที่รู้ URL สามารถยิงข้อมูลลง Sheet ของคุณได้ จึงเพิ่มระบบ **shared token** (แบบเลือกเปิด/ปิดได้) ให้แล้ว:

### วิธีเปิดใช้

1. **ฝั่ง Apps Script** — เปิด `Code.gs` ในหน้า Apps Script แก้ตัวแปรใน `doPost` ให้เป็นรหัสลับของคุณ:
   ```javascript
   const WEBHOOK_TOKEN = "ใส่-รหัส-ลับ-ของ-คุณ";
   ```
2. **ฝั่งหน้าเว็บ** — เปิด `index.html` (และ `js/app.js`) ค้นหาบรรทัด:
   ```javascript
   const GSHEET_TOKEN='';
   ```
   แล้วใส่รหัสเดียวกันกับที่ตั้งไว้ใน Apps Script:
   ```javascript
   const GSHEET_TOKEN='ใส่-รหัส-ลับ-ของ-คุณ';
   ```
3. Deploy โค้ด Apps Script ใหม่ (**Deploy** > **Manage deployments** > edit > **New version** > **Deploy**) และ deploy หน้าเว็บใหม่ตามปกติ

### ถ้าไม่ใส่รหัส

ตั้งค่าเป็น `""` (`WEBHOOK_TOKEN=""` และ `GSHEET_TOKEN=''`) ทั้งสองฝั่งระบบจะปิดการตรวจสอบ token โดยอัตโนมัติ — ใช้งานแบบเดิมได้ทันที ไม่ต้อง deploy ใหม่

> หมายเหตุ: หลังปุ่ม "ซิงค์ Google Sheet" ถูกกด ข้อความจะแจ้งว่า "โปรดตรวจสอบผลใน Sheet อีกครั้ง" เพราะการยิงโดยใช้ `mode: 'no-cors'` ยืนยันสถานะการตอบกลับจากเซิร์ฟเวอร์ได้ยาก
